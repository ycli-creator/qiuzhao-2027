# 2027 届秋招追踪（私有）

本地静态页，用来扫 2027 届校招（2026.9–2027.8 毕业）里和设计相关的公司、窗口、流程，并记下自己的投递进度。

**不要开 GitHub Pages。** 仓库保持 Private。进度只存在这台电脑的浏览器 `localStorage`，不会上传。

## 怎么打开

用浏览器直接打开 `index.html`，或在本目录：

```bash
npx serve
```

## 数据口径

- 面向 **2027 届**，岗位优先标 **UX / 视觉 / 动效 / 品牌 / 游戏美术**。
- 截止日期、是否笔试以官网实时页为准。表里的「核对日」是写入日期。
- 来源：各企业校园招聘官网，以及 2026-09-01 前后可核验的公开汇总。

## 进度

每一行的状态下拉会立刻写入本地。清站点数据会丢掉进度，清之前先自己导出或截图。
