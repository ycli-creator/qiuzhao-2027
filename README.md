# 2027 届秋招追踪

静态页，用来扫 2027 届校招（2026.9–2027.8 毕业）里和设计相关的公司、窗口、流程，并记下自己的投递进度。

公司名单共用。投递进度按名字分开存在 Supabase，你和朋友各记各的；换电脑选同一个名字即可继续。没填云端配置时，进度只留在当前浏览器。

## 怎么打开

用浏览器直接打开 `index.html`，或在本目录：

```bash
npx serve
```

## 云端（两人同步）

1. 在 [Supabase](https://supabase.com/dashboard) 新建一个免费项目。
2. 打开 SQL Editor，把 `supabase.sql` 整段跑一遍。
3. Project Settings → API，把 Project URL 和 `anon` `public` key 填进 `config.js`。

anon key 会进前端，这张表对拿到链接的人可读写。就两个人用可以接受。

## 数据口径

- 面向 **2027 届**，岗位优先标 **UX / 视觉 / 动效 / 品牌 / 游戏美术**。
- 截止日期、是否笔试以官网实时页为准。表里的「核对日」是写入日期。
- 来源：各企业校园招聘官网，以及 2026-09-01 前后可核验的公开汇总。

## 进度

进入时先选或新建一个名字。状态下拉会先写入本机，再同步到这个名字对应的云端一行。
